## 12. OBSERVACIONES OBJETIVAS

- El aviso de finanzas es un View con padding 12, radius 12 y fondo colors.warning.soft, con el botón "Reintentar" (secondary) dentro.
- El botón "Reintentar" llama a retryInventoryPurchaseFinance y, si funciona, muestra el toast "Registrada en Finanzas"; la pantalla no cambia de estado visible.
- El estado failed se distingue del éxito normal sólo por este bloque: el ícono de check verde se mantiene igual.

## 13. EFECTO PERCIBIDO

Un fallo de integración convive con el ícono de éxito completo: la señal visual de "todo bien" permanece y el problema se delega a un bloque de aviso amarillo.
